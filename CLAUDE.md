## What this repo is
- Personal fork of LmeSzinc/AzurLaneAutoScript (Azur Lane game bot, Python 3.7). Almost all code is upstream's.
- `.github/workflows/sync-upstream.yml` merges upstream/master into origin/master every hour
  (plain 3-way merge; never rebase or force-push master).
- The running app auto-updates itself from origin/master (`config/deploy.yaml`: AutoUpdate, 5-minute check).

## Hard rules
1. Both updaters run `git reset --hard origin/master` (`deploy/Windows/git.py`, `module/webui/updater.py`).
   Uncommitted edits to TRACKED files get wiped, unpushed commits can be too; untracked files survive.
   So finish a change, commit, and `git push origin master` right away. Never leave tracked edits lying around.
2. Keep the diff against upstream files minimal, or the hourly merge will conflict. Put fork code in NEW files
   (precedent: `module/webui/fork_widgets.py`, `module/webui/workflow_checker.py`, `assets/gui/css/alas-fork.css`,
   `dev_tools/fork_*.py`) and touch upstream files only through small additive hooks.
3. Fork commit messages: Korean, lowercase prefix (`add:`, `upd:`, `fix:`, `refactor:`), short title, then
   `- ` bullets, and NO `Co-Authored-By` trailer. Upstream's English `Add:`/`Fix:` style is not used here.

## Fork delta (never hand-maintain a list)
    git log --first-parent --no-merges --format= --name-only 92c07aa28..HEAD | sort -u
`92c07aa28` is the upstream commit the fork started from. If a traceback touches none of those files, it is an
upstream bug: check `git log -5 -- <file>` for a fresh upstream fix first, and prefer waiting for upstream over
carrying a patch in an upstream file.

## Debugging a runtime error
1. Run `./toolkit/python.exe dev_tools/fork_log_triage.py` FIRST. It condenses the newest scheduler log and GUI log
   (12k+ lines, MBs) to about 200 lines, states what it omitted, and expands with `--task`, `--since`, `--range`,
   `--file`. Its footer explains how `alas.py` treats each exception type and which ones leave a dump folder.
2. Never open a `log/*.txt` whole. Use the script's `--range A:B`.
3. Screenshots in `log/error/<ms>/` cost 1k+ tokens each; open only the last one or two.
4. Task name -> method of the same name (snake_case) in `alas.py` -> the module it imports.

## Do not read whole; grep the symbol or read a line range
- `**/assets.py` (45 files, generated by `dev_tools/button_extract.py`): grep the BUTTON_NAME.
- `module/island/data.py`, `module/research/project_data.py`, `module/config/config_generated.py`,
  `module/config/argument/args.json`, `module/config/argument/menu.json`, `module/config/i18n/*.json`,
  `config/template.json`.
- `campaign/event_*/` (1400+ generated map files): open only the stage in question.
- `toolkit/` is the bundled Python/Git/adb runtime, not project code.

## Environment
- Python is `./toolkit/python.exe`; do not assume a system Python.
- pytest is NOT installed. `tests/` needs `./toolkit/python.exe -m pip install pytest` first.
- Nothing in this repo may depend on its absolute path; the folder is portable and may be moved.
